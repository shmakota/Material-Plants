# Material Plants & Fluid Cows
Material Plants Originally by Spaghetti Admin. Adds mutated plants that grow materials like steel and gold. Crafted using buckwheat plants and mutagen. Requires cooking 7. This version adds a bunch more crops, and fixed the mod to be up to date to current BN standards.

![image](https://github.com/user-attachments/assets/4aa0766d-3a25-4b78-85e0-7803f0d71fd5)

Fluid Cows adds mutated cows that can be obtained through the catalyst cow. These cows can be milked for almost any liquid including fuel, oil, chocolate drink, soda, various chemicals and more.
